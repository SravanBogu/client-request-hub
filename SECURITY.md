# Security Policy

## Scope

This repository is a public, non-production reference implementation. It uses synthetic data only.

## Do not commit

- API keys, passwords, access tokens, certificates, or private keys
- Connection strings, `.env` files, publish profiles, or tenant IDs
- Client, employer, customer, employee, financial, healthcare, or operational data
- Internal URLs, screenshots, architecture diagrams, or configuration exports
- Power Platform connection credentials or exported secrets

## Reporting a vulnerability

Do not create a public GitHub issue for a security vulnerability.

## Supported versions

Only the latest `main` branch is maintained as a reference implementation.
