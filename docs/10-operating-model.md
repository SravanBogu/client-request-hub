# Operating Model

## Ownership

| Role | Responsibility |
|---|---|
| Business Owner | Process outcomes, policy, priorities, funding |
| Product Owner | Backlog, user acceptance, roadmap |
| Platform Architect | Architecture, governance, ALM, technical decisions |
| Makers/Developers | Build, test, document, fix defects |
| Support Team | Incident triage, user support, monitoring |
| Security/Compliance | Data classification, DLP, access and risk review |

## Support model

- Tier 0: User guidance and knowledge articles.
- Tier 1: Basic request and access support.
- Tier 2: Flow/app configuration and functional issues.
- Tier 3: Integration, platform, or Azure engineering issues.

## Change management

Changes require documented impact analysis, testing, approval, release notes, and rollback consideration.
