# Delivery Roadmap

## Phase 0: Discovery

- Map current state.
- Identify personas, data, approvals, SLAs, systems, and risks.
- Confirm MVP and measurable outcomes.

## Phase 1: MVP

- One request category.
- Intake form.
- Approval flow.
- Coordinator queue.
- Activity log.
- Basic reporting.

## Phase 2: Pilot

- Controlled user group.
- Training and feedback.
- Validate adoption, cycle time, and SLA results.
- Resolve defects and refine workflow.

## Phase 3: Scale

- Add request categories.
- Add Dataverse if needed.
- Add system integrations.
- Add SPFx command-center experience if needed.
- Add governed AI assistant for knowledge/status support.

## Phase 4: Operate and improve

- Monitor SLAs and flow failures.
- Review usage and business value.
- Maintain release/change process.
- Expand based on measurable outcomes.
