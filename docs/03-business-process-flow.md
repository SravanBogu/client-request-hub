# Business Process Flow

## Request lifecycle

1. Requester submits a request.
2. System validates required data.
3. Request status changes to Submitted.
4. Flow determines category, priority, SLA, and approver.
5. Approver approves or rejects.
6. If approved, the request is assigned to a coordinator.
7. Coordinator updates work progress.
8. SLA monitoring identifies aging or overdue work.
9. Coordinator completes the request.
10. Requester receives completion notification.
11. The activity log records key lifecycle events.
