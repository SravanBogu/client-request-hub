# Power Platform Implementation

## SharePoint-first MVP

Use SharePoint Lists when the process is collaboration-centric, the data model
is simple, business users need list visibility, and the solution can operate
within standard Microsoft 365 connector boundaries.

## Dataverse decision

Use Dataverse when the solution requires:

- Stronger relational data design.
- Role-based, row-level, or field-level security.
- Advanced audit requirements.
- Multiple business processes or applications.
- Model-driven app capabilities.
- Larger-scale transactional workloads.
- More controlled integration and ALM requirements.

## Power BI metrics

- Request volume by type, priority, and location.
- Pending approval count and aging.
- Average approval time.
- Average completion time.
- SLA compliance.
- Overdue request backlog.
- Rejection and rework trend.
