# Power Platform Implementation

This folder documents the planned low-code implementation of Client Request Hub.

## MVP components

- SharePoint Lists or Dataverse tables.
- Canvas App or SharePoint request form.
- Power Automate approval and notification flow.
- Teams/Outlook notifications.
- Power BI operational dashboard.

## Delivery principles

- Build in a dedicated development environment.
- Package Power Platform components in a solution.
- Use environment variables and connection references.
- Use synthetic data for development/demo work.
- Promote through Dev, UAT, and Production through governed ALM.
